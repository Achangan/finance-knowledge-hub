### 数据时效性说明（重要）

- Baostock / 腾讯的**当日日线约在 18:00 后**才发布，因此 16:00 的定时任务只能采到**上一交易日**数据
- 想让报告当天可用，需把 cron 从 `0 0 16 * * MON-FRI` 后移到 18:00 之后；今日已手动执行采集补齐 10-21 收盘数据
- 结论：**分析引擎不预测，只做事后统计**；看报告时先确认「生成时间」与「最新交易日」是否一致

### 踩坑记录

1. **建表语句被整条跳过**：按 `;` 切分后以 `--` 开头的语句被误判为注释，改为逐行剔除注释
2. **`change` 是 MySQL 保留字**：插入时报 1064，所有列名统一加反引号
3. **JDK 1.8 没有 `String.isBlank()`**：那是 Java 11 API，编译失败后全部改 `trim().isEmpty()`

5. **PowerShell 陷阱**：URL 里的 `&` 必须整体加引号；后台任务的 cwd 不生效，脚本要用绝对路径
