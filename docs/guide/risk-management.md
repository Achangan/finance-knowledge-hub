# 仓位管理与止损纪律

> **风险提示**：本节讲的是**风险控制规则**。A 股交易中，"活下来"比"赚得多"更关键——绝大多数爆仓案例都源于仓位与止损失守，而非选股错误。

## 一、为什么纪律比预测重要

A 股的**容错率低**：T+1 无法当日止损、涨跌停会锁死流动性、题材股一旦退潮连续跌停。在这三个约束下，任何"看对了方向但没管住仓位"的人都会亏钱。

| 场景 | 无纪律的结果 | 有纪律的结果 |
| --- | --- | --- |
| 买入后跌 10% | "再等等会反弹"，跌到 −30% | 触发止损离场，损失 −5% |
| 题材退潮 | 满仓被埋，连续跌停无法卖出 | 已减仓，损失可控 |
| 大级别下跌 | 本金腰斩，回本需涨 100% | 保留大部分本金，等下次机会 |

## 二、止损：三条可选规则

### 规则一：比例止损（最易执行）

| 类型 | 阈值 | 适用 |
| --- | --- | --- |
| 超短线 | −3% ~ −5% | 打板、隔日交易，容错极低 |
| 短线波段 | −5% ~ −8% | 持股数日至数周 |
| 中线持仓 | −8% ~ −10% | 基于基本面买入，给更多空间 |

> 公开的短线交易复盘普遍强调"**单笔交易最大亏损控制在 3%—5% 以内**"，理由是 A 股容错率低、扛单是大亏的根源。（来源：公开交易者经验总结，非学术统计）

### 规则二：逻辑止损（更严谨）

不是看亏了多少钱，而是看**买入理由是否还成立**：

| 买入理由 | 逻辑止损条件 |
| --- | --- |
| 突破箱体 | 价格跌回箱体内 → 突破失败 |
| 均线多头排列 | 跌破 MA20 且无法收回 |
| 业绩超预期 | 财报证伪或业绩预告变脸 |
| 行业政策利好 | 政策转向或被证伪 |

### 规则三：移动止损（保护浮盈）

| 浮盈水平 | 止损位上移规则 |
| --- | --- |
| +10% | 止损移至成本价（保本） |
| +20% | 止损移至 +10% |
| +30% | 止损移至 +20% |

### 三种规则的适配

| 交易类型 | 首选规则 | 原因 |
| --- | --- | --- |
| 超短线 | 比例止损 | 持仓时间短，无逻辑判断空间 |
| 波段 | 逻辑止损 + 比例兜底 | 兼顾结构与时点 |
| 中线 | 逻辑止损 + 移动止损 | 给基本面留出兑现时间 |

## 三、仓位管理

### 仓位上限（单笔风险法）

这是最通用的仓位公式：

```
单笔仓位 = 账户总资金 × 单笔可承受风险比例 ÷ 单笔止损幅度
```

**举例**：账户 100 万，规则是单笔风险不超过总资金 1%，止损幅度 5%：

```
仓位 = 100 万 × 1% ÷ 5% = 20 万
```

即在 5% 止损下，最多买 20 万——这样即使止损，也只亏总资金的 1%。

### 硬性上限（简单直接）

| 限制项 | 建议上限 | 理由 |
| --- | --- | --- |
| 单只个股 | ≤ 20% 总仓位 | 避免单一公司风险 |
| 单一行业 | ≤ 30% 总仓位 | 避免行业系统性风险 |
| 总权益仓位 | 按承受能力定 | 参见"风险与收益的关系"一节 |
| 杠杆（两融） | 保守者 0 | 杠杆放大亏损速度 |

### 加仓与减仓的节奏

| 方法 | 做法 | 适用 |
| --- | --- | --- |
| **金字塔加仓** | 越涨加仓幅度越小（如 4:3:3 → 逐次减少） | 趋势确认后 |
| **倒金字塔（禁忌）** | 越跌加仓越多、摊薄成本 | ❌ 最危险的做法 |
| **退一进二** | 上涨过程中主动降低仓位、下跌中逐步提高 | 逆向仓位控制 |
| **情绪匹配仓位** | 冰点轻仓、发酵加仓、高潮减仓、退潮空仓 | 题材股行情 |

> "退一进二"的核心是**与多数人的加仓节奏相反**：多数人追涨加仓时你降仓，多数人恐慌时你有余粮。（来源：中国证券报《仓位控制三技法》）

### 情绪周期对应的仓位区间（参考）

| 阶段 | 仓位区间 | 原则 |
| --- | --- | --- |
| 冰点期 | 0—2 成 | 保存实力优先 |
| 发酵期 | 3—5 成 | 确认主线后逐步提高 |
| 高潮期 | 逐步降至 2—3 成 | 兑现利润 |
| 退潮期 | 0 成 | 空仓等下一个周期 |

## 四、止盈：把浮盈变成现金

### 分批止盈法

| 阶段 | 操作 |
| --- | --- |
| 达到目标涨幅 1/3 | 卖出 1/3，落袋为安 |
| 再涨 1/3 | 再卖 1/3 |
| 剩余仓位 | 用移动止损保护 |

公开的短线体系中有"**走出 20%—30% 波段后优先减仓收回全部本金**"的做法——即先保住本金，剩下的用"零成本仓位"去博弈，心理压力大幅下降。（来源：公开交易者经验总结）

### 止盈的两难

- **不止盈**：坐过一次大涨又全部回吐的人，心态会崩
- **过早止盈**：牛市里容易"卖飞"，错过主升浪
- **折中方案**：**分批 + 移动止损**，兼顾兑现与持有

## 五、交易日志：唯一能持续改进的工具

每个交易记录以下字段：

| 字段 | 内容 |
| --- | --- |
| 买入日期 / 价格 | — |
| 买入理由 | 一句话说明，越具体越好 |
| 止损位 | 明确价格或条件 |
| 仓位占比 | 占总资金比例 |
| 卖出日期 / 价格 | — |
| 卖出理由 | 触发止损？达到目标？情绪驱动？ |
| 复盘结论 | 这笔交易赚钱是靠运气还是靠逻辑？ |

**判断标准**：如果连续 20 笔交易的"复盘结论"多数是"运气"，说明你的策略没有正期望。

## 六、A 股特有的资金安全陷阱

| 陷阱 | 说明 | 防范 |
| --- | --- | --- |
| **场外配资** | 以 5—10 倍杠杆放大仓位，本身属违规违法金融活动 | 绝不使用；平台跑路、强平风险极高 |
| **荐股群 / 付费带单** | 交费进群"跟着老师做"，多为拉高出货的接盘方 | 不参与；正规投顾需持牌且不得承诺收益 |
| **非法私募 / 代客理财** | 资金无托管、承诺保本高息 | 只通过持牌机构交易 |
| **"内幕消息"** | 内幕交易本身违法，且消息到散户手上时已被消化 | 不参与 |
| **虚假交易软件** | 非官方渠道下载的"行情/交易软件"可能盗取账户 | 只从券商官网 / 官方应用商店下载 |

## 七、一页速查：下单前的四条铁律

1. **先定止损，再定仓位**——止损幅度决定你能买多少
2. **单笔亏损不超过总资金 1%—2%**
3. **单只个股不超过总仓位 20%**
4. **触发止损无条件执行**——纪律永远大于预判

> **一句话总结**：A 股交易技巧中，唯一被反复验证有效的那一条是——**控制住单笔亏损和总仓位**。所有"战法"都会失效，只有纪律能在失败时保住你的本金。
