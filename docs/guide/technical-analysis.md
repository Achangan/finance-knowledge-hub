# 技术分析入门（K 线与形态）

技术分析不是预测未来的水晶球，但理解 K 线和常见形态有助于识别趋势、判断买卖时机。**技术分析 ≠ 短线投机**——它服务于已经通过基本面选好的标的。

## K 线基础

### 一根 K 线的四要素

| 位置 | 含义 |
| --- | --- |
| 上影线顶端 | 最高价 |
| 下影线底端 | 最低价 |
| 实体上沿 | 开盘价 / 收盘价 |
| 实体下沿 | 收盘价 / 开盘价 |
| 红色（阳） | 收盘 > 开盘（上涨） |
| 绿色（阴） | 收盘 < 开盘（下跌） |

### 重要单根 K 线

| 形态 | 含义 |
| --- | --- |
| **大阳线** | 实体饱满，强烈看涨信号 |
| **大阴线** | 实体饱满，强烈看跌信号 |
| **十字星** | 开盘 = 收盘，多空激烈博弈，变盘信号 |
| **锤子线 / 射击之星** | 下影长 / 上影长，分别是底部 / 顶部反转信号 |
| **孕线 / 吞没** | 后一根 K 线完全包含前一根，反转信号 |

## 常见反转形态

| 形态 | 位置 | 可靠性 | 说明 |
| --- | --- | --- | --- |
| **头肩顶** | 顶部 | 高 | 中间峰值最高，两侧次高，跌破颈线确认 |
| **头肩底** | 底部 | 高 | 反向，中间最低 |
| **双顶（M 顶）** | 顶部 | 中 | 两次冲到同一高点后回落 |
| **双底（W 底）** | 底部 | 中 | 两次踩到同一低点后反弹 |
| **圆弧顶 / 圆弧底** | 顶 / 底 | 中 | 缓慢趋势反转，可靠性较高 |
| **V 型反转** | 底部 | 低 | 暴跌后急速拉升，假信号多 |

## 常见持续形态

| 形态 | 方向 | 含义 |
| --- | --- | --- |
| **三角形** | 水平收敛 | 波动收窄，突破后延续原方向 |
| **上升 / 下降通道** | 向上 / 向下 | 在两条平行线内运行，触及上下轨为买卖点 |
| **旗形 / 楔形** | 与主趋势相反 | 短暂整理后突破延续原方向 |
| **矩形（箱体）** | 横盘 | 在固定区间内震荡，上沿卖、下沿买 |

## 均线系统

均线 = 过去 N 天收盘价的平均值。**最常用最有效的技术指标**。

### 常见均线

| 周期 | 含义 |
| --- | --- |
| MA5 | 5 日线，短期趋势 |
| MA20 | 20 日线，中短期趋势 |
| MA60 | 60 日线，中期趋势（3 个月） |
| MA120 | 半年线 |
| MA250 | 年线，长期趋势分界线 |

### 均线的经典用法

| 信号 | 含义 |
| --- | --- |
| 股价在 MA250 上方 | **牛市倾向** |
| MA5 上穿 MA20（金叉） | 短期趋势转好 |
| MA5 下穿 MA20（死叉） | 短期趋势转坏 |
| MA60 走平后向上拐头 | 中期趋势反转向上 |
| 均线多头排列（MA5 > MA20 > MA60） | 强势上涨格局 |

### 均线的缺点
- **滞后**：趋势反转后均线才会转向
- **震荡市频繁假信号**：来回金叉死叉

## 成交量

量在价先——量能是价格的先行指标。

| 量价关系 | 含义 |
| --- | --- |
| 放量上涨 | 正常上涨，多头主动 |
| 缩量上涨 | 上涨动能不足，警惕见顶 |
| 放量下跌 | 恐慌性抛售，可能短期见底 |
| 缩量下跌 | 抛压枯竭，企稳信号 |
| 高位放量滞涨 | **强烈见顶信号**（量能不支持继续上攻） |
| 低位放量突破 | **强烈见底信号**（资金涌入建仓） |

## 技术分析的正确打开方式

1. **先长期后短期**：先看周线 / 月线判断大趋势，再看日线 / 小时线找买卖点
2. **多指标共振**：均线 + 形态 + 量能同时发出信号，可靠性才高
3. **严格止损**：即使技术分析正确，也要预设止损（通常 -8% 到 -10%）
4. **不迷信精确预测**：技术分析是概率判断，对错都要执行纪律

## 技术分析的常见误区

| 误区 | 真相 |
| --- | --- |
| "某个形态 100% 准确" | 没有任何形态的胜率超过 70% |
| "主力画图" | 大部分技术形态是市场整体行为的结果，不是某一方刻意画的 |
| "靠技术分析稳定赚钱" | 技术分析只是辅助，长期稳定盈利靠的是**组合、纪律、成本控制** |
