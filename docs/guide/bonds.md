# 债券基础与定价

债券是借钱的凭证：发行人（国家、企业）向投资者借钱，承诺定期付息、到期还本。比股票风险低，但同样有定价逻辑和利率风险。

## 债券的核心要素

| 要素 | 含义 |
| --- | --- |
| 票面金额 | 到期归还的本金（通常 100 元） |
| 票面利率 | 每年支付的利息占票面的比例 |
| 付息方式 | 按年付息 / 半年付息 / 到期一次还本付息 |
| 期限 | 短期（1 年以内）、中期（1—10 年）、长期（> 10 年） |
| 发行人 | 政府（国债）、金融机构、企业 |

## 债券分类

| 类型 | 发行人 | 信用等级 | 收益率特征 |
| --- | --- | --- | --- |
| 国债 | 中央政府 | 最高（无风险） | 最低收益率 |
| 地方政府债 | 地方政府 | 很高 | 略高于国债 |
| 政策性金融债 | 国开行等 | 很高 | 略高于国债 |
| 信用债（AAA） | 头部民企 / 国企 | 高 | 比国债高 0.5%—1% |
| 信用债（AA+ 以下） | 中小民企 | 中低 | 溢价更高，有违约风险 |
| 可转债 | 上市公司 | 中 | 低于同等级信用债 + 可转股权期权 |

## 债券定价：价格为什么会变

```
债券现值 = Σ(利息 ÷ (1 + 贴现率)^t) + 本金 ÷ (1 + 贴现率)^n
```

### 核心关系：**利率与债券价格反向变动**

| 利率变动 | 已有债券价格 |
| --- | --- |
| 利率上行 | ❌ 下跌（新债券利率更高，老债券没人要） |
| 利率下行 | ✅ 上涨（老债券利率更高，溢价交易） |

### 久期（Duration）：衡量价格对利率的敏感度

久期越长，利率变动对债券价格影响越大：

| 久期 | 利率上行 1% 的价格影响 |
| --- | --- |
| 2 年久期 | 约 −2% |
| 5 年久期 | 约 −5% |
| 10 年久期 | 约 −10% |
| 20 年久期 | 约 −20% |

> **久期 × 利率变动幅度 ≈ 债券价格变动幅度**（近似，利率变化较小时成立）

## 债券收益率的几种说法

| 说法 | 含义 | 你真正关心的 |
| --- | --- | --- |
| 票面利率 | 债券每年按面值给多少利息 | 只是表面 |
| 当期收益率 | 年利息 ÷ 当前市价 | 静态，忽略资本利得 |
| **到期收益率（YTM）** | 按当前价格买入并持有到期的**真实年化收益率** | **最关键** |

### YTM 的反直觉特性

- 利率下行期买入高票息债券，YTM 看起来不高，但**价格上涨**可以额外获得资本利得
- 利率上行期买入低票息债券，YTM 看起来诱人，但**价格下跌**会吃掉一部分收益

## 中国主要债券市场

| 市场 | 参与主体 | 交易方式 | 流动性 |
| --- | --- | --- | --- |
| 银行间市场 | 机构为主 | 场外 OTC | 高 |
| 交易所市场（上交所 / 深交所） | 机构 + 散户 | 场内竞价 | 中 |
| 柜台市场 | 散户 | 银行渠道 | 低 |

### 个人投资者能直接买的债券

| 渠道 | 产品 | 最低门槛 |
| --- | --- | --- |
| 交易所 | 国债、可转债、企业债 | 100 元起 |
| 银行柜台 | 凭证式国债 | 100 元起 |
| 债券基金 | 投资债券组合 | 10 元起 |
| 银行理财（R2） | 投资债券为主 | 1 万起（新规后下降） |

## 债券投资的主要风险

| 风险 | 含义 | 如何应对 |
| --- | --- | --- |
| 利率风险 | 利率上行债券价格下跌 | 控制久期，或用短期债 / 滚动持有 |
| 信用风险 | 发行人违约 | 只投高评级（AA+ 以上），分散 |
| 流动性风险 | 想卖卖不出去 | 选活跃交易的品种 |
| 再投资风险 | 到期再投资时利率已经下行 | 用债券基金自动滚动 |
| 通胀风险 | 实际收益被通胀侵蚀 | 搭配其他资产 |

## 久期策略实操

| 市场判断 | 久期策略 | 工具 |
| --- | --- | --- |
| 利率将下行 | 拉长久期 | 10 年期国债 ETF（如 511260） |
| 利率将上行 | 缩短久期 | 货币基金、逆回购、1 年期以内债券 |
| 方向不明 | 哑铃策略（长 + 短两头） | 货币基金 + 长期国债 |

## 债券 vs 其他资产的定位

| 对比 | 结论 |
| --- | --- |
| 债券 vs 股票 | 波动小但长期收益低；债券提供稳定性，股票提供成长性 |
| 债券 vs 银行理财 | 打破刚兑后债券收益更高，但有净值波动 |
| 债券基金 vs 直接买债券 | 基金自动分散、管理久期，普通投资者更省心 |
