# 估值方法（PE / PB / DCF）

估值就是回答：**这只股票现在值不值得买**？没有一种方法万能——不同行业适用不同估值模型，且估值本质上是"比较"：相对于历史、相对于同业。

## 核心估值指标

### PE（市盈率）

```
PE = 当前股价 ÷ 每股收益（EPS）
```

- **TTM PE**：滚动 12 个月的 EPS（最常用）
- **静态 PE**：上一年度年报的 EPS
- **动态 PE**：预测未来一年的 EPS

| PE 区间 | 含义 | 适用阶段 |
| --- | --- | --- |
| < 15 倍 | 低估 | 成熟期公司 |
| 15—30 倍 | 合理 | 正常增长 |
| > 30 倍 | 高估 / 高增长 | 高成长股 |

> **PE 反推年化收益率 = 100% ÷ PE**。PE 20 倍 = 理论年化 5%（假设全部利润分红）。

### PB（市净率）

```
PB = 当前股价 ÷ 每股净资产
```

- 净资产 = 资产 − 负债 = 股东权益
- **PB < 1**：破净（价值陷阱？还是真低估？）
- **强周期性行业**（银行、券商、地产）常用 PB
- **重资产行业**（制造业、航运）PB 参考价值高

### PS（市销率）

```
PS = 当前股价 ÷ 每股营业收入
```

- 适合**尚未盈利但有高增长营收**的公司（互联网 SaaS、创新药、早期科技）
- 缺点：不反映成本和利润

### PEG（PE / 增长率）

```
PEG = PE ÷ 未来 3—5 年净利润增速（%）
```

| PEG | 含义 |
| --- | --- |
| < 1 | 低估（增长能支撑估值） |
| ≈ 1 | 合理 |
| > 1 | 高估 |

PEG 把 PE 与成长性结合，更适合成长股估值。

### EV / EBITDA

- EV = 市值 + 有息负债 − 现金（企业总价值）
- EBITDA = 息税折旧摊销前利润
- 剔除资本结构差异，适合**重资产行业、并购估值**

## 不同行业估值范式

| 行业 | 首选方法 | 原因 |
| --- | --- | --- |
| 银行、保险、地产 | PB | 盈利不稳定 / 周期性 |
| 消费（白酒、食品） | PE / PEG | 盈利稳定、分红高 |
| 科技（AI、半导体） | PS / 远期 PE | 高增长、短期盈利薄 |
| 医药（创新药） | DCF / 管线估值 | 未来现金流不确定 |
| 能源（煤炭、石油） | PB + 股息率 | 强周期、重资产 |
| 互联网 | PE / PS / 用户价值 | 用户规模、平台效应 |

## DCF（现金流折现）

DCF 是理论上最严谨的估值方法：**任何资产的价值 = 未来所有自由现金流的折现值之和**。

### 基本公式

```
V = Σ(CF_t ÷ (1 + WACC)^t) + TV ÷ (1 + WACC)^n
```

| 参数 | 含义 |
| --- | --- |
| CF_t | 第 t 年自由现金流 |
| WACC | 加权平均资本成本（折现率） |
| TV | 终值（期末剩余价值） |
| n | 预测期（通常 5—10 年） |

### 难点
1. **自由现金流预测**：需要预测营收、成本、资本开支等，对未来假设敏感
2. **WACC 选择**：通常 8%—12% 区间，包含股权风险溢价
3. **终值 TV**：占 DCF 估值的 50%—70%，假设永续增长率（通常 2%—3%）

### 实操
- 专业机构常用，普通投资者手工算较难
- 券商研报通常会给出 DCF 估值区间
- 可用于**排除极端高估 / 低估**，但不要精确到个位数

## 估值的正确姿势

### 估值不是给数字，而是画区间

| 方法 | 乐观假设 | 中性假设 | 悲观假设 |
| --- | --- | --- | --- |
| PE（TTM） | 25 倍 | 20 倍 | 15 倍 |
| 对应市值 | 500 亿 | 400 亿 | 300 亿 |

### 估值"锚"从哪来

1. **历史估值区间**：这家公司过去 10 年 PE/PB 的中位数
2. **同业可比公司**：同行业其他公司的平均估值
3. **市场整体估值**：沪深 300 历史 PE 中位数约 13 倍

### 估值陷阱

| 陷阱 | 案例 |
| --- | --- |
| PE 低但盈利不可持续 | 周期高点的煤炭、地产 |
| PB 低但资产质量差 | 应收账款 / 商誉占比高的公司 |
| 增速高估 | 把过去 3 年高增长线性外推 |
| 行业天花板 | 行业整体增速下行，估值中枢下移 |

## 股息率作为估值锚

对成熟、稳定分红的公司（银行、高速公路、公用事业）：

```
股息率 = 年度现金分红 ÷ 当前股价
```

- A 股股息率历史中枢约 2%
- **> 5%** 的高股息率通常较有吸引力（对比 10 年期国债）
- 但需确认分红的**可持续性**（看过去 5 年是否稳定分红）
