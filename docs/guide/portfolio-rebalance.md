# 投资组合构建与再平衡

资产配置给出了"目标比例"，组合构建是"怎么买"，再平衡是"怎么管"——三者缺一不可。

## 构建投资组合的 6 个步骤

### Step 1：确定各资产类别的目标比例

| 资产 | 目标比例 |
| --- | --- |
| A 股宽基指数 | 30% |
| 全球股票（港股 / 美股） | 20% |
| 债券（国内 + 全球） | 35% |
| 现金（货币基金） | 10% |
| 黄金 / 另类 | 5% |

### Step 2：选择具体投资工具

| 目标 | 工具 | 费率 |
| --- | --- | --- |
| A 股宽基 | 沪深 300ETF（510300）+ 中证 500ETF（510500） | 0.15% |
| 全球股票 | 标普 500ETF（513500）+ 恒生科技 ETF（513180） | 0.5% |
| 债券 | 易方达增强回报债券基金（A 份额） | 0.4% |
| 现金 | 货币基金（天弘余额宝） | 0 |
| 黄金 | 华安黄金 ETF（518880） | 0.5% |

**选择原则**：**费率优先、规模其次、历史业绩垫底**。

### Step 3：分批建仓

不要一次性满仓：
- 已有现金：分 3—6 次买入（每月一次），避免买在短期高点
- 已有投资：先清仓不想要的旧品种 → 按新比例重新分配
- 极端市场（如指数从高点回撤 > 20%）可以加速建仓

### Step 4：记录基准

建仓完成后，记下**每个品种的建仓成本、持仓比例、初始日期**——后续所有判断都要与这个基准对比。

## 再平衡（Rebalancing）

组合里各资产的涨跌不同步，比例会偏离目标。再平衡就是把比例拉回来的操作。

### 为什么要再平衡

| 情况 | 结果 | 不调整的后果 |
| --- | --- | --- |
| 股市大涨，权益从 50% → 65% | 股票占比过高 | 熊市来时亏损被放大 |
| 股市大跌，权益从 50% → 35% | 股票占比过低 | 牛市来时踏空 |
| 债券上涨，固收从 30% → 40% | 固收占比过高 | 长期收益偏低 |

### 两种再平衡策略

| 策略 | 规则 | 频率 | 适合 |
| --- | --- | --- | --- |
| **定期再平衡** | 每季度 / 半年 / 一年一次 | 固定周期 | 大多数人（简单好记） |
| **阈值再平衡** | 某类资产偏离目标 > 5% / 10% 时触发 | 不定期 | 主动管理型投资者 |

**推荐组合**：**年度检视 + 5% 阈值触发**。每年末看一次，有资产偏离目标比例超过 5% 就调整，否则不动。

### 再平衡的操作方法

| 方法 | 做法 | 优点 |
| --- | --- | --- |
| **用新增资金调整** | 每月定投时，把新增资金全部买入占比不足的资产 | 无需卖出，成本低 |
| **被动调整** | 涨得好的资产有分红时，分红再投入到其他资产 | 同样低成本 |
| **主动卖出买入** | 直接卖出超配、买入低配 | 精准，但有交易成本 |

**优先顺序**：新增资金调整 → 分红再投资 → 主动卖出买入。

## 再平衡的"反直觉"效果

- 再平衡本质是**高抛低吸**：涨多了就卖一点（高抛），跌多了就补一点（低吸）
- 回测显示，纪律性再平衡的组合收益**略低于从不调整的组合**（因为牛市中股票占比高才赚得多）
- 但再平衡能**显著降低组合波动**，从而让你在熊市中**拿得住**——这才是它真正的价值

## 不适合再平衡的情况

| 情况 | 建议 |
| --- | --- |
| 你的某只卫星股 / 行业 ETF 已经上涨太多 | 可以止盈一部分，不用强制拉回 |
| 你判断某类资产长期逻辑已变化 | 可以主动调低目标比例（比如 2022 年后不再重仓地产） |
| 你是定投新手，只有少量钱刚开始投 | 先定投积累，等资金量上来后再做再平衡 |

## 组合健康度自检

建议每季度回答以下 5 个问题：

1. 我的各资产占比是否在目标比例 ±5% 以内？
2. 我的权益类资产最大回撤历史上超过 30% 时，我会怎么操作？
3. 我持有的基金里，有多少是"一年前不知道为什么买的"？
4. 我有没有同时持有风格严重重叠的品种（如沪深 300 + 中证 A50ETF）？
5. 我的现金 + 货币基金够覆盖 **6—12 个月生活费**吗？

如果有 2 个以上答不上来，说明需要一次组合审视。
