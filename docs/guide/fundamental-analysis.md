# 基本面分析（财务三表）

基本面分析 = 读懂公司的财务报表，判断这家公司的**盈利能力、成长性、健康程度**。核心是三张表：利润表、资产负债表、现金流量表。

## 财务三表速览

| 报表 | 回答的问题 | 关注的核心科目 |
| --- | --- | --- |
| 利润表 | 赚了多少钱？ | 营业收入、营业成本、净利润、毛利率 |
| 资产负债表 | 家底有多厚？ | 资产总额、负债总额、净资产（股东权益） |
| 现金流量表 | 手头真金白银够不够？ | 经营活动现金流、投资活动、筹资活动 |

## 一、利润表（P&L）

```
营业收入
 − 营业成本
= 毛利润
 − 费用（销售 + 管理 + 研发 + 财务）
 ± 公允价值变动损益 / 投资收益 / 资产减值
= 营业利润
 ± 营业外收支
= 利润总额
 − 所得税
= 净利润
```

### 关键比率

| 指标 | 公式 | 怎么看 |
| --- | --- | --- |
| 毛利率 | (营收 − 成本) ÷ 营收 | 越高越好；反映产品竞争力；行业差异极大 |
| 净利率 | 净利润 ÷ 营收 | 越高越好；反映最终赚钱效率 |
| ROE | 净利润 ÷ 平均股东权益 | **最重要的盈利能力指标**；巴菲特长期关注 ≥ 15% 的公司 |
| ROA | 净利润 ÷ 平均总资产 | 反映资产使用效率 |
| 营收增速 | (本期 − 上期) ÷ 上期 | 判断成长性 |
| 净利润增速 | 同上 | 同上；需与营收增速对比判断是否"增收不增利" |

### ROE 的杜邦拆解

```
ROE = 净利率 × 资产周转率 × 权益乘数
```

| 因素 | 含义 | 提升方式 |
| --- | --- | --- |
| 净利率 | 盈利能力 | 产品提价、成本控制 |
| 资产周转率 | 资产使用效率 | 轻资产运营、存货周转快 |
| 权益乘数 | 杠杆 | 借债经营（但杠杆有风险） |

## 二、资产负债表（Balance Sheet）

```
资产 = 负债 + 股东权益
```

### 资产端（公司的东西）

| 分类 | 主要科目 | 关注要点 |
| --- | --- | --- |
| 流动资产 | 货币资金、应收账款、存货 | 应收账款高 → 可能收不回来；存货积压 → 可能减值 |
| 非流动资产 | 固定资产、无形资产、商誉 | 商誉过大需警惕（减值风险） |

### 负债端（公司的债）

| 分类 | 主要科目 | 关注要点 |
| --- | --- | --- |
| 流动负债 | 短期借款、应付账款 | 短期借款过多 → 流动性风险 |
| 非流动负债 | 长期借款、应付债券 | 利率变动影响 |

### 关键比率

| 指标 | 公式 | 怎么看 |
| --- | --- | --- |
| 资产负债率 | 总负债 ÷ 总资产 | 越低越稳健；银行业除外（天然高杠杆） |
| 流动比率 | 流动资产 ÷ 流动负债 | ≥ 2 较健康 |
| 速动比率 | (流动资产 − 存货) ÷ 流动负债 | ≥ 1 较健康 |
| 有息负债率 | 有息负债 ÷ 总资产 | 剔除经营性负债后更能反映真实杠杆 |

## 三、现金流量表

这是**最容易被粉饰**却也**最能反映真实状况**的表。

### 三大活动

| 活动 | 含义 | 健康信号 |
| --- | --- | --- |
| **经营活动** | 主营收付款 | **持续为正**，且金额 ≥ 净利润 |
| 投资活动 | 买卖固定资产、金融资产 | 负（公司在扩张）通常正常 |
| 筹资活动 | 借债、还债、发股、分红 | 看公司是靠内生增长还是靠融资 |

### 关键判断：净利润 vs 经营现金流

| 情况 | 含义 | 风险 |
| --- | --- | --- |
| 净利润 + 经营现金流 + | ✅ 最健康 | — |
| 净利润 + 经营现金流 − | ⚠️ 赚了利润但没收到钱 | 应收账款高、利润质量差 |
| 净利润 − 经营现金流 + | ⚠️ 可能利润表有一次性费用 | 看原因 |
| 净利润 − 经营现金流 − | ❌ 最差 | 亏损 + 现金流失血 |

## 高频操纵手段

| 手段 | 对应科目 | 怎么识别 |
| --- | --- | --- |
| 虚增收入 | 应收账款 + 营收同步大增 | 对比同行业；看现金流 |
| 隐藏成本 | 存货、商誉 | 存货周转大幅下降；商誉异常增长 |
| 调节利润 | 公允价值变动、资产减值 | 每年减值计提/转回集中在年末 |

## 行业特殊指标速查

| 行业 | 核心指标 |
| --- | --- |
| 银行 | 净息差、不良贷款率、资本充足率 |
| 保险 | 内含价值（EV）、新业务价值（NBV）、偿付能力 |
| 房地产 | 负债率、存货周转、现金流 |
| 互联网 | DAU/MAU、ARPU、付费率 |
| 制造业 | 存货周转、应收账款周转、ROIC |
