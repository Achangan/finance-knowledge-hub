# 基金类型与结构

公募基金是普通投资者参与股市债市最便利的工具。理解基金的分类、费用、运作方式，是挑选基金的前提。

## 公募基金核心分类

### 按投资方向

| 类别 | 资产配置 | 典型产品 | 风险 |
| --- | --- | --- | --- |
| 货币基金 | 100% 短期存单、逆回购、同业存单 | 天弘余额宝、易方达易理财 | 极低 |
| 债券基金 | ≥ 80% 债券 | 易方达增强回报、招商产业债券 | 低 |
| 股票基金 | ≥ 80% 股票 | 华夏回报、兴全合润 | 中高 |
| 混合基金 | 股债灵活（0—100%） | 董承非管理过的兴全趋势、富国天惠 | 中 |
| QDII 基金 | 投资境外资产 | 标普 500ETF、恒生科技 ETF | 中高 |
| FOF | 80% 投资其他基金 | 养老目标基金 | 中 |

### 按运作方式

- **开放式基金**：随时申购赎回，绝大多数基金都是此类
- **封闭式基金**：发行后封闭运作一段时间（如 3 年），期间在交易所上市交易，有折价 / 溢价
- **定期开放式基金**：设定开放期（如每年一次）

### 按投资理念

- **主动型基金**：基金经理主动选股，追求超越基准
- **被动型基金**（指数基金 / ETF）：完全复制指数，不做主动选股

## 主动 vs 被动：谁赢

全球范围内（美国）：
- 80% 以上主动基金跑不赢对应指数
- 跑赢的那 20%，第二年继续跑赢的概率不到 50%（"冠军魔咒"）

中国市场：
- 主动基金超额收益略高于美国，但持续性同样不佳
- 2015—2020 年一批"明星基金经理"（葛兰、张坤、刘彦春等）2021 年后普遍回撤 30%—50%

**结论**：普通投资者优先选择**宽基指数基金 / ETF**，节省主动管理费 + 避免择时选错基金经理。若选主动，必须长期跟踪 + 分散多只。

## 基金费用结构

| 费用 | 收取环节 | 费率区间 | 备注 |
| --- | --- | --- | --- |
| 申购费 | 买入时 | 1.5% 左右（打一折后 0.15%） | 第三方平台普遍一折 |
| 赎回费 | 卖出时 | 持有 < 7 天：1.5%<br>持有 ≥ 7 天：0 | 惩罚短期交易 |
| 管理费 | 每日从基金资产计提 | 1.5% / 年（主动）<br>0.5% / 年（被动） | **隐形但持续** |
| 托管费 | 同上 | 0.15% / 年 | 银行托管费 |
| 销售服务费 | 同上（C 份额） | 0.4% / 年 | 用于持续营销，A 份额无 |

### A vs C 份额（常见混淆）

| 份额 | 申购费 | 销售服务费 | 适合 |
| --- | --- | --- | --- |
| A 份额 | ✅ 一次性 | ❌ 无 | **长期持有（> 2 年）** |
| C 份额 | ❌ 无 | ✅ 每年 | **短期持有（< 2 年）** |

## 基金挑选的 5 个维度

1. **基金规模**：太小（< 1 亿）有清盘风险；太大（> 500 亿）灵活度下降。通常 20—200 亿较合理
2. **成立年限**：至少经历一轮牛熊（≥ 3 年），排除"新基金蜜月"
3. **最大回撤**：比收益率更能反映风险水平。查看 2022 年、2020 年 3 月的表现
4. **基金经理稳定性**：任职年限、跨产品风格一致性、是否频繁跳槽
5. **费用率**：同类基金比费率，同样业绩下低费率的长期收益更高

## 避坑清单

| 坑 | 怎么防 |
| --- | --- |
| 追"年度冠军基金" | 冠军魔咒：第二年大概率跑输，看 3—5 年业绩而非 1 年 |
| 认购新发基金 | 新发基金有封闭期 + 建仓期 + 认购费（不打折），不如老基金 |
| 看"累计净值"买基金 | 累计净值包含分红再投资，误导；看**单位净值走势 + 累计分红** |
| 频繁换基金 | 每次交易产生费用 + 择时失败概率，典型"追涨杀跌" |
